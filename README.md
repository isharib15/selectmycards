# SelectMyCards - Intelligent Credit Card Recommendation Engine 💳

**Live Demo:** [selectmycards.com](https://selectmycards.com)

## 🚀 The Problem
Finding the right credit card in India is broken. Users are bombarded with spam calls, confusing terms, and hidden fees. Existing aggregators require phone numbers (leading to spam) before showing results.

## 💡 The Solution
**SelectMyCards** is a privacy-first recommendation engine.
* **Zero Personal Data:** No phone number or email required to see results.
* **Algorithm-Driven:** Calculates "Real Reward Value" based on user spending habits (Travel vs. Dining vs. Fuel).
* **Instant Matching:** Filters 50+ cards in <100ms based on Income & Credit Score eligibility.

## 🛠️ Tech Stack
* **Frontend:** React.js, Tailwind CSS (Mobile-First Architecture)
* **Logic:** Custom filtering engine (Weighted scoring algorithm for card ranking)
* **Deployment:** Vercel (CI/CD Pipeline automated)
* **Analytics:** Google Analytics 4 + Search Console Integration

## 🌟 Key Features
1.  **"Trust Signal" Design:** UX optimized for high conversion without dark patterns.
2.  **Responsive Dashboard:** Full feature parity across Mobile (iPhone/Android) and Desktop.
3.  **Dynamic Filtering:** Real-time sorting based on income tiers and spending categories.
